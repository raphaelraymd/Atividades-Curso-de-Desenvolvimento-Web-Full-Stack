O que é o DOM?

O DOM (Document Object Model) é uma representação em árvore de um documento HTML ou XML. Ele permite que os desenvolvedores acessem e manipulem a estrutura, estilo e conteúdo de uma página web usando JavaScript.

Eventos

Eventos são ações ou ocorrências que acontecem no navegador, como cliques, movimentos do mouse, teclas pressionadas, entre outros.
