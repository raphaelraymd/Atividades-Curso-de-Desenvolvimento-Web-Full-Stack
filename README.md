# Atividades-Curso-de-Desenvolvimento-Web-Full-Stack
Repositório criado para armazenar as atividades, exercícios e projetos desenvolvidos durante o curso de Desenvolvimento Web Full Stack.
Aqui estão reunidos estudos práticos envolvendo:
- HTML5
- CSS3 e Tailwind CSS
- JavaScript
- Lógica de Programação
- Consumo de APIs
- Responsividade
- Banco de Dados
- Desenvolvimento Front-End e Back-End

O objetivo deste repositório é acompanhar minha evolução na programação, praticando conceitos fundamentais e desenvolvendo aplicações web modernas.
